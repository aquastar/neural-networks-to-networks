# From Networks to Neural Networks

What internal structure tells us about generative models. A tutorial talk built with reveal.js.

Play online: https://aquastar.github.io/neural-networks-to-networks/

Keys: Space or arrows to advance, Esc or O for the slide overview.

Figures reproduced from the cited papers remain the property of their authors and publishers.


## Style
index.html, deck.js and wb3d.js are generated in the house style v2 by `python3 src/restyle.py` from src/original.html, src/deck.original.js and src/wb3d.original.js. Edit the originals, then rerun. src/style_v2.py is the same module used by aquastar/graph-inside-generative-models.
